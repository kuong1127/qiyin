栖音 Qiyin 0.2.10 · 任务栏播控

一、安装与启动
双击“Qiyin-Setup-0.2.10-win-x64.exe”，按提示完成安装。
适用 Windows 11，Intel / AMD 64 位电脑；已包含 .NET 运行环境，无需另外安装。
安装结束勾选“立即启动栖音”，或使用桌面 / 开始菜单快捷方式。
请先打开 QQ 音乐或网易云音乐，播放一首歌曲。无歌曲时组件可能自动隐藏。
同一时间只运行一个播控实例；若旧版本已在运行，请先在旧版本右键菜单选择“退出”。

二、播放器首次设置
QQ 音乐：设置 → 常规设置 → 通知 → 开启“系统媒体传输控件（SMTC）”。
网易云音乐：设置 → 系统 → 勾选“开启 SMTC”。开启后可同步播放 / 暂停图标。
网易云爱心使用全局快捷键，请在“设置 → 快捷键”启用全局快捷键，并把“喜欢音乐”设为 Ctrl+Alt+L。
如果使用了不同的喜欢快捷键，可在组件右键菜单打开配置文件后修改。
播放器须已登录，歌曲须允许收藏。播放器安装包和账号数据不包含在本包内。

三、使用
点击封面：播放器已在前台时最小化；已最小化、隐藏或被其他窗口遮挡时恢复到前台。
上一首 / 下一首：切歌。
播放时显示双竖线，暂停时显示三角形。
爱心：加入 / 取消喜欢；QQ 音乐已支持在组件中取消收藏。
拖动歌曲文字区域：调整播控位置；位置会自动保存。
右键组件或系统托盘图标：调整显示、开机启动或退出。
按钮鼠标悬停不弹出中文提示。

四、歌词与进度
QQ 音乐：有匹配歌词和有效播放进度时显示同步歌词；支持的歌曲可点击 / 拖动进度条。
网易云音乐：当前原生接口未提供真实时间轴，因此本版不提供网易云同步歌词和进度跳转。
本安装包未加入网易云第三方歌词扩展。
纯音乐、无歌词曲目或网络获取失败时显示艺人信息。

五、卸载与配置
在 Windows“设置 → 应用 → 已安装的应用”中找到“栖音”并卸载。
更新安装保留已有配置；卸载也保留配置和歌词缓存，便于以后重新安装。
配置位置：%APPDATA%\TaskbarMediaBar\settings.json
本包不包含使用者的收藏记录、登录信息、历史日志或个人配置。

本版本未购买代码签名证书。安装包来源请以提供者给出的文件和 SHA-256 校验值为准。
