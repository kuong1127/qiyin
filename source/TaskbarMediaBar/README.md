# 栖音 Qiyin 0.2.20 源码保存

本目录保存 Windows WPF/.NET 8 项目的源码、测试、默认配置、品牌图标和打包脚本。该快照提供常驻顶部长条与既有任务栏播控模式。仓库根目录的 main 分支说明和既有发布素材保持原样。

默认仍使用任务栏模式。通过播控条或托盘右键菜单中的「播控位置 → 屏幕顶部」启用顶部模式；可以切回任务栏。顶部默认 360×40 DIP，保留封面、两行文字/歌词、播放控制和底部进度条，支持横向拖动及全屏、手动和无媒体时的显隐规则。

媒体信息来自 Windows SMTC；不支持 SMTC 的播放器使用项目现有的窗口标题和全局快捷键兜底路径。可用的进度、歌词和播放状态取决于播放器提供的能力。收藏等真实账号操作需另行实测。

## 构建

使用 Windows 与 .NET 8 SDK，在本目录运行：

~~~powershell
dotnet build TaskbarMediaBar.csproj -c Release
~~~

测试项目位于 Tests/。如运行测试，请为 TMB_DATA_DIR 指定独立输出目录；部分原生集成和 Live 测试会创建窗口或操作播放器，运行前应阅读测试代码。
